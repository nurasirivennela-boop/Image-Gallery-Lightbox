# 🖼️ Responsive Image Gallery with Lightbox

A responsive image gallery with a lightbox effect built using HTML, CSS and JavaScript.

## Features

- Responsive image grid
- Lightbox image viewer
- Enlarged image view
- Previous and next navigation
- Close button
- Image captions
- Image counter
- Keyboard navigation
- Mobile responsive design
- Accessible alt text

## Technologies Used

- HTML5
- CSS3
- JavaScript
